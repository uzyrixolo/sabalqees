# sabalqees — Balqees KSA Shopify theme

Connected to Shopify theme **KSA AR - homepage** (`187639628086`) on store `sa-balqees`.

Pushes to `main` sync automatically into the theme via the Shopify GitHub integration.

## Arabic migration
`ar` is the store's **primary** locale, so Arabic lives as the *source* text in
theme files (`templates/*.json`, `config/settings_data.json`, `locales/ar.json`) —
not as Shopify translation records. See `arabic-migration/STATUS.md` in the
working repo for full context.
